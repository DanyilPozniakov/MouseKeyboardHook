# MouseKeyboardHook

A tiny app that records and plays back mouse and keyboard events and includes a simple numeric keypad UI.

Quick start:

Usage

- Start Hook — begin recording mouse/keyboard events.
- Stop Hook — stop recording.
- Play Recorded Events — replay recorded events (the input field is focused before playback).
- Loop Playback — toggle automatic repeating of playback.
- Stop Playback — stop replaying events.
- Clear All — clear log and recorded events.
